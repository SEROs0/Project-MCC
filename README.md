# 🏥 MedCare Clinic — Full Stack Web Application 

ระบบจองคิวและบริหารจัดการคลินิกออนไลน์ พัฒนาด้วย React.js

---

## 🩺 เกี่ยวกับโปรเจกต์

MedCare Clinic เป็น Web Application สำหรับระบบจองคิวและดูประวัติการรักษาของคลินิก
ผู้ป่วยสามารถเข้าสู่ระบบด้วยหมายเลข HN เลือกแพทย์ เลือกเวลานัด
และดูประวัติการรักษาย้อนหลังได้ทันที

---

## ⚙️ การติดตั้ง

**1. Clone โปรเจกต์:**
```bash
git clone https://github.com/username/mcc-frontend.git
cd mcc-frontend
```

**2. ติดตั้ง dependencies:**
```bash
npm install
```

**3. รันโปรเจกต์:**
```bash
npm start
```

**4. เปิดใน browser:**
